# Research: agent harness design & multi-agent coding workflows

Scope: papers and repos on agent-computer-interface design, harness architecture, multi-agent
orchestration, test-time compute allocation, file-lease/conflict-avoidance, subscription-seat
arbitrage, and supervision protocols. Excludes anything already vendored per ROADMAP.md §4
(aider, mini-swe-agent, ACP SDK repos, claude-squad, conductor, llm-council, spec-kit, serena,
repomix, etc.) unless a *new* fact about it surfaced. Every row was fetched and read, not
guessed from a title.

## Top 5 actions (novelty × demand ÷ effort)

1. **Build `core/quota.py`'s rotation state machine from Claudexor + teamclaude, not from scratch.** Three independent shipped tools converged on the same algorithm: rotate only on a *typed* vendor-exhaustion signal, pause (don't rotate) on an ordinary rate-limit 429 for its `retry-after` window, never rotate on a generic network error, track quota per-model not per-account, and prefer the soonest-reset account among rotation candidates. This is ROADMAP §3's own #1-ranked novel tool, and it no longer needs to be designed from first principles — it needs to be copied and adapted to ForgeOS's ledger.
2. **Add one generic ACP adapter instead of more hand-rolled per-CLI adapters.** The Zed ACP registry now lists 25+ agents speaking one stable JSON-RPC-over-stdio protocol (Claude Agent, Codex CLI, Gemini CLI, OpenCode, Cursor, Copilot, Junie, Goose, and others). One adapter file turns every future entrant in that registry into a free worker.
3. **Adopt RTV/PDR (distill-then-tournament) as `Router.escalate`'s best-of-N mode.** ForgeOS already committed to "compact supervision" as a cost lever; this paper is the concrete algorithm for applying that same instinct to *retries*, with measured SWE-bench Verified gains attached, rather than raw parallel transcripts or blind sequential retries.
4. **Wire a Bors-style bisecting batch-merge into the merge gate**, per Gas Town: batch concurrently-finished workers' merge candidates, verify the batch, bisect only on failure. Serializing merge checks one worker at a time throws away exactly the parallelism the worktree-per-worker design already paid for.
5. **Encode the Anthropic/Cognition decomposition checklist as a manager pre-flight check**: before marking two TaskSpecs parallel-safe, require non-overlapping `Scope.paths` *and* no shared not-yet-materialized contract (a signature, schema, or interface one task will introduce that another's tests reference). Turns a public cross-vendor disagreement into one concrete gate that prevents the exact silent-divergence failure mode both sides independently reported.
